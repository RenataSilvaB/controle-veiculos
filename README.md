
# Sistema de Controle de Veículos 

Projeto desenvolvido com o objetivo de praticar o desenvolvimento Full Stack, utilizando Angular no Front-End e Node.js com Express no Back-End.

##  Objetivo

Desenvolver uma aplicação para gerenciamento de veículos, permitindo realizar operações de cadastro, consulta, atualização e exclusão de registros.

##  Tecnologias utilizadas

### Front-End
- Angular
- TypeScript
- SCSS

### Back-End
- Node.js
- Express
- TypeScript

### Ferramentas
- Git e GitHub
- Postman
- Visual Studio Code

##  Funcionalidades

- [ ] Listar veículos
- [ ] Cadastrar veículos
- [ ] Editar veículos
- [ ] Excluir veículos
- [ ] Pesquisar veículos
- [ ] Filtrar veículos por status
